# 🧶 Knotera – Handmade E-commerce Website

Knotera is a full-stack e-commerce website designed for selling handmade **Macramé and Crochet products**.

The project provides a complete shopping experience with product browsing, user authentication, shopping cart, checkout, demo payment flow, order management, and an admin panel.

---

## ✨ Features

- 🏠 Handmade-themed responsive homepage
- 🛍️ Product listing and collection
- 🪢 Macramé category
- 🧶 Crochet category
- 👤 User registration and login
- 🛒 Add to Cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove items from cart
- 💳 Checkout system
- 💰 Demo online payment flow
- 📦 Order placement
- 📋 My Orders section
- 🛠️ Admin panel
- 📊 Product and order management
- 📱 Responsive design
- 🎨 Modern glassmorphism-inspired UI
